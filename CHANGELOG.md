# Changelog

## 2.0.0-dev.2

Public ecosystem baseline.

- Added the Apache-2.0 license.
- Standardized the public ecosystem repository as graphx2-packages.
- Kept the GraphX 2 public API/runtime baseline used by the first-party packages.

## 2.0.0-dev.1

Work in progress toward GraphX 2.

- Brought the current core into a standalone package.
- Kept the existing rendering, input, focus, semantics, portals, tests, and benchmarks.
- Cleaned the public package surface.
- Standardized GraphX naming.
- Changed node `name` values and Stage options to named arguments.
