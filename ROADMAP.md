# Roadmap

GraphX 2 starts with a small goal: make the core feel great to use again.

## Now

- finish the public API cleanup
- keep the core fast, predictable, and easy to read
- build a proper examples gallery
- test the same examples on web, iOS, Android, and desktop
- start the GraphX website around real demos instead of static documentation
- keep benchmarks and regression tests close to the features they protect

## Next

- improve the everyday creative workflow around drawing, interaction, assets, text, and composition
- make debugging and inspection easier while working on scenes
- add more stress demos for large scenes, filters, caching, input, and multiple views
- make examples easy to open, copy, tweak, and share

## Later

GraphX can grow in many directions, but those ideas do not need to shape the core before they are proven useful.

This roadmap is intentionally loose. It is a list of things worth exploring, not a package map or a release schedule.
